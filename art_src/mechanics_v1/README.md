## Нарезка и привязки

Фактические размеры, SHA-256, области элементов, предлагаемые pivots и проверка альфы — в [mechanics_manifest_v1.json](mechanics_manifest_v1.json). Полные промпты и уточнение повторной генерации паровоза — в [mechanics_prompts_v1.json](mechanics_prompts_v1.json). Неудачный промежуточный PNG в пакет не включён. Выбранные PNG скопированы без обработки, альфа сохранена.

Это исходники для последующей нарезки. Равномерная сетка безопасна только у паровоза: остальные листы имеют свободную раскладку, и обычное деление высоты на число рядов пересечёт объекты. Использовать `rect_px` из манифеста; координаты начинаются в левом верхнем углу, формат `[x, y, ширина, высота]`. `visible_bbox_local_alpha_ge_32` показывает видимую область внутри вырезки; слабые полупрозрачные края за ней сохранять. У демона ширина областей меняется, чтобы не отрезать когти и осколки.

Паровоз: совмещать ось пути по точке у кончика метельника, а не по центру дыма; pivots заданы отдельно для каждого кадра. Лава: привязка сверху к своду. Щит: общий центр у основания купола, прозрачный центр предназначен для отдельного слоя поезда. Перед анимацией эффекты и демона дополнить прозрачными полями до общего размера холста. Предложенные 8–10 кадров/с — стартовая настройка для интеграции.

## Проверка и ограничения

Все пять PNG имеют настоящий канал RGBA с полностью прозрачными пикселями. Проверены размеры и альфа через Pillow, элементы просмотрены на контрастном фоне: цвет фона в скрытом RGB не переносится при корректном альфа-композитинге. Полупрозрачность по краям и у эффектов намеренно сохранена. Центр купола пропускает фон, лавовые и световые акценты не требуют непрозрачного прямоугольника.

Это художественные исходные фазы, а не уже подключённые игровые атласы. Генерация даёт небольшие различия фактуры, пропорций и положения между кадрами; точную регистрацию, темп и стык цикла 4→1 проверить при сборке анимации. Единую физическую пиксельную сетку генератор не гарантирует; использовать nearest и общий масштаб. Код, игровые ассеты и сцены не изменялись.
