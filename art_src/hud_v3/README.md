# Приборная доска — HUD v3

Эталон: `art_src/keyframes_v1/01_furnace_390x844.png`. Оригинальная генерация встроенным
image_gen сохранена в `drafts/`, точные запросы — `hud_prompts_v3.json`.
Подготовка: `python art_src/hud_v3/prepare.py`; проверка без пересборки: та же команда с `--check-only`.
Python 3.12 + Pillow, без новых зависимостей. Скрипт только для производства арта.

Игровые PNG — `assets/ui/hud_v3/`. Палитра строго 32 цвета из `docs/STYLE.md`,
альфа 0/255, nearest, без сглаживания. Цифры собственные: ячейка 12×18, advance 12,
baseline 15. Слова не запечены. Промежуточные генерации и проверочные доски не игровые текстуры.

`hud_manifest_v3.json` описывает размеры, кадры, pivots, область 9-slice и назначение;
это документация для интегратора, не второй реестр игры. Insets 9-slice — left/top/right/bottom
в пикселях PNG. При масштабе ×2 углы и края сохраняют размер, растягивается центр.
Низ 195×72 → 390×144 CSS px; запас до ограничения 150 — 6 px. Манометр и портрет 58×58.
Стрелка отдельная, её hub `[5,30]` совмещается с `[29,30]` манометра.

`previews/hud_390x844.png` — композиция игровых PNG поверх художественного эталона,
не снимок игры. Низ начинается на y=700, заканчивается на y=844. Интеграция в DOM
и поведение показателей выполняются отдельной карточкой; JS этим пакетом не меняется.

Шесть `portrait_*`: calm / tense / joy / hit / fire / fall — спокоен, напряжён, рад,
получил удар, перегрелся в огне, падает. Один машинист `engineer_01`: одинаковая фуражка,
крупный нос, тёмные усы и седые виски; верх фуражки и нижний край шарфа унифицированы
побайтно. Холст 48×48, позиция относительно рамки `[5,6]`; рамка накладывается сверху.
`previews/portraits_six_states.png` показывает каждый портрет отдельно и внутри рамки при ×2.

## Состав: 45 игровых PNG

| Часть | Файлов | Размер PNG |
|---|---:|---|
| Верх, низ, манометр, стрелка, рамка лица, гнездо счётчика | 6 | в манифесте |
| Цифры 0–9 | 10 | 12×18 |
| Лицо: шесть реакций | 6 | 48×48 |
| Значки: 5 показателей, 3 опасности, ускорение, тормоз, пауза, настройки | 12 | 24×24 |
| Пикапы: boost, slow, shield, ammo, rescue | 5 | 24×24 |
| Плашка меню ×3 состояния, кнопка ×3 состояния | 6 | 160×220 и 138×28 |

`icon_*` — отдельные силуэты, `pickup_*` — те же обозначения в восьмиугольном
металлическом жетоне. `icon_gap` имеет явно разорванные рельсы, `icon_lava` — каплю,
`icon_demon` — рога и оранжевые глаза. Крюк, провал и глаза демона доведены вручную
на конечной сетке. `previews/icons_48_and_menu.png`: каждый значок ровно 48×48 px,
ниже normal / pressed / disabled. Нажатие утопляет плоскость и переворачивает блик,
отключение заменяет тёплую латунь холодным чугуном; прозрачность не снижать.

Плашка подходит для четырёх существующих экранов из `docs/qa/menu/`: главное меню,
режимы, настройки, магазин. Текст, ползунки и интерактивное состояние остаются в DOM.
Кнопка 138×28 при ×2 даёт 276×56 CSS px; уменьшать тач-цель ниже 44 px нельзя.
Плашку меню растягивать 9-slice по двум осям; у кнопки преимущественно по горизонтали.
`content_insets` задаёт безопасную область. На pressed текст можно сдвигать вниз на 2 CSS px.

Соответствие действующему `UILayout.js`: `dist` → icon_distance + digit_*;
`best` → icon_record + digit_*; `ammo`, `shield`, `rescue` → одноимённые значки;
`pauseBtn` → icon_pause; `frameTop` / `frameBottom` → bar_top / bar_bottom.
`iconLane*` / `iconWall*` получают hazard или pickup по факту из правил забега.
Указанные примеры не вводят новых игровых показателей: число в манометре — запас патронов
в демонстрационной композиции, значение/смысл поворота стрелки должен задать интегратор.
Длинный счётчик растягивает counter_socket горизонтально; число не обрезать.

`previews/hud_camera2_390x844.png` — отдельная композиция поверх существующего QA-кадра
`docs/qa/default/play-390x844.png` камеры ×2. Область мира `[0,78,390,700]` сохранена
побайтно, верхняя панель занимает 78 px, нижняя — y=700…843, то есть 144 px.
Это проверка площади и арт-сборки, не доказательство интеграции в работающий DOM.
Эталонное художественное превью рядом показывает предполагаемый итоговый стиль мира.

`validation.json`: SHA-256, размеры, альфа и ноль цветов вне палитры для каждого PNG,
включая RGB полностью прозрачных пикселей. Все исходники сохранены; воспроизведение
генератора не требуется, сборка идёт из трёх готовых draft PNG.
