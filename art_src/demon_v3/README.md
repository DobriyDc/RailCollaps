# Демон из кладки — v3

Один оригинальный персонаж `furnace_mason_01`: два кирпичных рога, тяжёлая кирпичная
челюсть, угольное тело, Y-образная магма в груди, три когтя на каждой кисти.
Эталон материалов — `art_src/keyframes_v1/01_furnace_390x844.png`.

Первый этап: четыре кадра стойки, стопы закреплены, верх тела дышит на 0–2 пикселя.
Генерация встроенным image_gen в `drafts/`; точный запрос в `demon_prompts_v3.json`.
`python art_src/demon_v3/prepare.py` пересобирает PNG из сохранённых исходников;
`--check-only` проверяет каждый игровой файл, включая RGB прозрачных пикселей.
Python 3.12 + Pillow; скрипт только для производства арта.

Игровые файлы — `assets/sprites/demon_v3/`, холст 160×160, палитра из STYLE,
альфа 0/255, фильтрация nearest. Манифест описывает кадры, pivots и длительности
для интегратора; это не второй реестр ресурсов игры. Для левой стены отразить X
и опорные точки: x → 159−x. Скорость фаз задают правила карточки 36.

`previews/perch_390x844.png` — две зеркальные стойки поверх художественного
эталона, проверка на огне и тёмной стене; это арт-композиция, не снимок игры.
`previews/contact_sheet.png` показывает PNG в родном масштабе ×1.
