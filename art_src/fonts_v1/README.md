# Шрифт интерфейса: Alagard и его кириллица — v1

2026-11-02, по просьбе владельца: готический пиксельный шрифт для всего интерфейса.

**Латиница** — Alagard, автор Hewett Tsoi (Pix3M), `assets/fonts/alagard.ttf`, файл без изменений.
Скачан с dafont.com (`dl.dafont.com/dl/?f=alagard`), условие автора: «Give credit if used. That's it.»
Имя автора стоит в игре на экране настроек (`fontCredit`). В Alagard 100 знаков, кириллицы нет.

**Кириллица** нарисована здесь на сетке Alagard: em 16 px, заглавные 11, строчные 8, нижние выносные 3,
основной штрих 2 px, флажок сверху слева, ножка справа внизу. Буквы того же вида, что латинские
(А В Е К М Н О Р С Т Х а е о р с х), взяты из Alagard пиксель в пиксель, остальные нарисованы
заново, Ё ё Й й собраны из основы и знака. Плюс знаки текстов игры: · — – … ‹ › « » − ✓.

- `alagard_cyrillic.txt` — исходник: блок на знак, 16 строк от y=12 до y=−3, `#` — пиксель.
- `preview.png` — алфавит и строки игры ×4.
- `node tools/make-font.mjs` собирает `assets/fonts/alagard_cyrillic.ttf` (TrueType без пакетов,
  каждый пробег пикселей — прямоугольный контур), `--check` сверяет файл с исходником.

`js/UI.js` объединяет оба файла под семейством "Alagard" через unicode-range; знак, которого нет
ни в одном (▶, ⭐), берётся из системного шрифта. `tests/font.test.mjs`: файл совпадает с исходником,
каждая буква текстов игры есть в одном из двух файлов, unicode-range покрывает каждый знак кириллицы.

Проверено: оба файла загружаются в Edge (OTS их принимает), подписи на экранах 360×800, 320×568
и в широком 844×390 на русском и английском помещаются в свои кнопки и панели. FreeType из Pillow
со своим автохинтингом сдвигает надстрочные знаки Й, й и ✓ на 16 px; контуры при этом верные.
