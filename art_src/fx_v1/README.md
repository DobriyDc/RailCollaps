# Эффекты движения и урона — v1

Оригинальный пакет для карточки 15, 30.10.2026. Исходные растры созданы встроенным
image_gen с прозрачным фоном; Pillow нарезает их и приводит к крупной сетке 2 px.
Все девять полных запросов и параметры подготовки — [fx_prompts_v1.json](fx_prompts_v1.json).
Нет текста в изображениях. Игровые PNG не содержат пикселей эталона.

Всего 40 отдельных кадров (`имя_00_v1.png` и далее) и 9 горизонтальных листов.
Порядок слева направо, без промежутков. Размеры атласов, rect кадров, опорные точки
в пикселях от левого верхнего угла и normalized, назначение и тайминг находятся в
[fx_manifest_v1.json](fx_manifest_v1.json). Это описание арта для карточки 16,
не второй runtime-реестр.

Рекомендации подключения: nearest, без mipmaps, unlit, обычное alpha blending.
Альфа 0/128/255: редкие полупрозрачные пиксели оставлены для пара и кромок,
нет размытого свечения. Для противоположной смены полосы зеркалить дым и искры
по X вместе с pivot (`x' = ширина − x`). Искры ставить в контакты колёс, пар —
у трубы; когти и щит — поверх котла. Пепел — вторичный акцент удара, когти дают
основной сигнал. Щит имеет прозрачный центр. Обломки — 4 объекта, а не четыре
состояния одного объекта: выбирать независимо и двигать по траектории падения.
Для разового эффекта после последнего кадра скрывать спрайт; последняя фаза
содержит затухающие частицы. Горячий пар повторять только пока нужен перегрев.

Проверка изображений:

- [Все листы](preview_all_sheets_v1.png): ряды идут в порядке таблицы.
- Каждый `preview_<имя>_v1.png` — три панели **360×640**, ранняя, средняя и
  последняя фазы. Точные индексы и якоря записаны в манифесте; у лавы средняя
  фаза 03 — уже распад после пика 02, который виден в обзоре и анимации.
- Каждый `preview_<имя>_motion_v1.png` — APNG для проверки движения; просмотрщик
  без APNG покажет первый кадр. У обломков показывает смену вариантов.
- Превью — художественные наложения на эталон с паровозом, не скриншоты игры.
  Они проверены при 1:1; подключение в живую сцену выполняется карточкой 16.

Воспроизведение: `python art_src/fx_v1/build_pack.py` из корня проекта.
Скрипт читает сохранённые `source_*_v1.png`, ничего не генерирует в сети и не
меняет код игры. Он обрезает общий для фаз прямоугольник после отсечения альфы
меньше 32, сохраняет единый масштаб и размещение всех кадров листа, ограничивает
палитру, увеличивает nearest и проверяет непустые уникальные кадры и прозрачные поля.
[validation_v1.json](validation_v1.json) хранит численные результаты.
