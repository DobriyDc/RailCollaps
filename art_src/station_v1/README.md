# Станция — игровые спрайты и ключевые кадры v1

## Игровой набор, 02.11.2026

Оба стиля приняты: A «Алтарь топки» и B «Собор в руинах». Готовы **40 PNG**:
37 в `assets/sprites/station/` и 3 значка в `assets/ui/hud_v3/`.
Новые стены, арка и предметы не содержат черепов, крестов, рун, букв или цифр.
Рогатый мотив раннего ключевого кадра A отменён; старые ключевые кадры ниже —
архив обсуждения, а не источник для интеграции. Использовать только новый набор.

- Две плоские стены 384×192, полностью заполненные по центру за поездом;
  рваный верх прозрачен, нижняя кромка — уровень рельсов.
- Восемь общих пассажиров: стойка лицом и два шага вправо, всего 24 PNG 32×64;
  высота силуэта 48–56 px, подошвы на y64. Влево отражает движок.
- Четыре непрозрачные плитки: верх 128×128 повторяется по x/y, борт 128×32 по x.
  Согласованы четыре крайних полосы; на превью каждый тайл показан повтором 3×3.
- Арка A 384×224: две опоры, обычный замковый камень, прозрачный центр;
  нижние 64 px проёма имеют непрерывную свободную ширину минимум 300 px.
- Два огня жаровни A 40×56, пустая клетка A 32×48 с цепью до верха,
  два огня колонны B 32×128, общий столб 40×120 с пустой табличкой 36×28.
  В анимационных парах основание одинаково; меняется пламя.
- Три значка 24×24: ремонт (молоток с заплатой), латунный жетон и скамья.

Все игровые PNG — RGBA, альфа только 0/255, все RGB (включая скрытые) строго
из 32 цветов `docs/STYLE.md`. Ассеты уменьшаются непосредственно до своей
конечной сетки, без целого увеличения; проверяются все делители размеров.
Точка привязки — низ по центру в пикселях; у плиток [0,0]. Перспективу и свет
задаёт движок, яркими остаются источники огня/лавы и светящиеся проёмы.

**5 новых вызовов встроенного image_gen, 8 суммарно с тремя ключевыми кадрами.**
Сырые листы: `drafts/sprites/{wallA,wallB,passengers,tiles,props}.png`.
Точные запросы: `station_sprites_prompts_v1.json`; размеры, pivots, назначение,
SHA-256 и результаты проверок: `station_sprites_manifest_v1.json`.
`sprites_preview.png` показывает все спрайты ×3 nearest на `#14121a` с именами,
а также каждую плитку повтором 3×3, тоже ×3 nearest. Подписи только на превью.

Воспроизведение: `python art_src/station_v1/prepare.py` — нарезка, подгонка
силуэтов и таблички, периодические края, палитра, бинарная альфа, проверка
40 размеров, высоты пассажиров, проёма арки, анимационных пар и целого увеличения.
Архивную обработку ключевых кадров отдельно вызывает аргумент `--keyframes`.
Код игры не менялся; подключение и случайное чередование A/B выполняет координатор.

Проверка: `python art_src/station_v1/prepare.py` — код 0, 7,7 с.
`node tools/check.mjs --tests` целиком — код 0, 13,7 с.

## Архив ключевых кадров

Два оригинальных варианта для выбора владельца, 390×844; не игровые спрайты.

- `station_A_390x844.png` — «Алтарь топки»: чёрные рёбра с шипами, рогатый череп,
  пустые клетки, жаровни и лавовые желоба. По три пассажира на каждой платформе.
- `station_B_390x844.png` — «Собор в руинах»: разрушенный стрельчатый фасад,
  оранжевые проёмы, костяные шипы, багровые минеральные наросты, боковые аркады.
  По четыре пассажира на каждой платформе.
- `compare_station_v1.png` — основа, A, B слева направо ×1 на `#14121a`;
  снизу фрагменты обеих платформ A и B ×3 nearest, с полным ростом пассажиров.
  Это фрагменты ключевых кадров с окружением, не нарезка спрайтов.

Использовано **3 вызова встроенного image_gen**: первый A с силуэтами отправлен до
дополнения о людях; второй A заменил их пассажирами; один вызов B сразу с пассажирами.
Все три исходных PNG сохранены без изменений в `drafts/`. Модель инструмента не раскрывается.
Запросы — `station_prompts_v1.json`, размеры, pivot, проверки и SHA-256 —
`station_manifest_v1.json`. В B дополнительно запрошено сохранить поезд в y200–450,
дым в y140–220, фасад в y100–215 и людей по сторонам в y255–390.

Референсы владельца: огненный алтарь с железными рёбрами, разрушенный готический собор
и стоковый пример простых пропорций людей. Они использованы только локально как
ориентиры архитектуры и пропорций, в публичный репозиторий не включены.
Персонажи оригинальные: рабочие куртки, кепки, платки, шали, сумки, чемоданы и фонарь;
лица без черт, приглушённая одежда. В `refs/` только три кадра игры `base_*.png`.

## Палитра и сохранение основы

Исходный `base_stop` содержит 583 цвета вне STYLE. По прямому уточнению координатора
приоритет имеет точное сохранение RGB игры: поезд, дым, передний путь и обе панели
восстановлены из исходника без приведения. Вся нижняя половина начиная с y422,
верхняя панель y<85, нижняя панель y>700 и таймер сохранены пиксель в пиксель.
Маска поезда и дыма описана в `prepare.py`.

**Новый арт строго в 32 цветах `docs/STYLE.md`; каждый пиксель вне палитры совпадает
с `base_stop` в той же точке.** В каждом итоге 555 унаследованных цветов вне палитры
(4125 пикселей), новых внепалитровых пикселей — **0**, изменений защищённых пикселей — **0**.
Это согласованное исключение для исходного кадра, а не заявление о 0 внепалитровых
цветов во всём композите.

Новый арт обработан как `keyframes_v1/prepare.py`: BOX до 166×360, слабый Bayer 4×4,
ближайший RGB палитры, увеличение nearest до 390×844. Затем восстановлены пиксели
игры. У нового растра нет размытия и полупрозрачных краёв.

Воспроизведение и проверки: `python art_src/station_v1/prepare.py`.
Скрипт проверяет размеры, обе панели, защищённые области и совпадение всех
внепалитровых пикселей с основой; результаты сохраняет в манифест.
Для интеграции после выбора владельца понадобятся отдельные ассеты и объём станции:
перспектива здесь служит только ключевым кадром. Код игры не менялся.

Проверки 02.11.2026: `python art_src/station_v1/prepare.py` — код 0, 6,0 с;
`node tools/check.mjs --tests` целиком — код 0, 14,9 с, 251 тест пройден.
Визуально проверены оба кадра и сравнение с увеличенными пассажирами.
