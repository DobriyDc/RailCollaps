# Текстуры 3D-тоннеля v1

29.10.2026. Оригинальные материалы созданы встроенным **image_gen**, затем доведены Python 3.12 + Pillow. Стиль сверялся с `storyboard_tunnel_style_keyframe_v1.png` и `storyboard_tunnel_motion_6frames_v1.png`: тёмная коричневая кладка, ржавый металл, зернистый крупный пиксель, ступенчатый свет. Перспектива в текстуры не запечена.

## Игровые файлы

Все файлы находятся в `assets/textures/tunnel/`, каждый **128×128 PNG**.

| Имя | Повторение | Назначение |
|---|---|---|
| `brick_wall.png` | X, Y | Боковые стены, горизонтальная кладка |
| `vault_brick.png` | X, Y | Развёртка свода, длинная ось кирпича вдоль V |
| `arch_rib.png` | Y | Каменное ребро арки / пилястра |
| `floor_ballast.png` | X, Y | Отсыпка между путями |
| `track.png` | Y | Две прямые рельсы, четыре шпалы, гравий; вид сверху |
| `lava_0.png`…`lava_3.png` | X, Y | Четыре кадра поверхности лавы |
| `torch_glow.png` | нет, clamp | Световая декаль с настоящей прозрачностью |

X = ширина PNG / U; Y = высота PNG / V. Направление пути — Y. Точки привязки — центр `[0.5, 0.5]`; у материала на меше положение задаёт UV. Повторение поперёк пути и поперёк ребра арки не требуется.

## Исходники и доводка

- `generated/`: семь нетронутых PNG от image_gen, по одному материалу на изображение.
- `tunnel_textures_prompts_v1.json`: полные точные промпты, происхождение и способ доводки.
- `build_textures.py`: воспроизводимая сборка из сохранённых исходников; запуск из любой папки: `python art_src/tunnel_textures_v1/build_textures.py` из корня репозитория.
- `tunnel_textures_manifest_v1.json`: файлы, размеры, палитры, оси повторения, pivot, кадры и назначение.

Кладка пересобрана из сгенерированных лицевых поверхностей в точную сетку раствора; свод повёрнут в UV. У отсыпки и лавы исходные границы перенесены сдвигом в центр, закрыты внутренними фрагментами по минимальному цветовому разрыву и жёсткому пиксельному срезу. На краях добавлен однопиксельный wrap guard. У пути выправлены прямые головки рельсов. Размытие, сглаживание и дизеринг не применялись; материалы содержат до 24 цветов, лава — 16, путь — до 29, декаль — 8 RGB-цветов со ступенчатой альфой.

Лава движется сдвигом одной периодической поверхности на 32 пикселя по Y за кадр: `0 → 1 → 2 → 3 → 0`. Все четыре перехода, включая последний, проверены на точное совпадение со сдвигом. Предложенный темп — 180 мс/кадр (цикл 720 мс), без смешивания кадров; скорость можно настроить при интеграции.

Декаль сохраняет альфу генератора, сведённую к ступеням 0, 32…224, с прозрачным полем. Рекомендуется additive-наложение с учётом alpha на кирпич, clamp по U/V; не включать bloom. Материалы использовать с nearest-фильтрацией в рендере 360×640.

## Проверка

В `previews/` лежат отдельные `*_3x3.png` для **всех десяти** игровых файлов, общий `all_3x3.png`, обзор `contact_sheet.png`, увеличенный путь и `lava_loop.gif`. Превью 3×3 просмотрены: разрывов на заявленных осях не обнаружено; регулярный раствор и повторяющиеся камни — часть рисунка материала. Световая декаль показана повтором только для проверки прозрачного поля, тайлинг ей не назначен.

Сборка проверяет 10 размеров 128×128, четыре точных перехода лавы и диапазон альфы декали. `node tools/check.mjs --tests` — **код 0, 89 тестов, стена 0,886 с**. Существующие ассеты и код сцены не изменены; пакет готов для подключения через UV материалов 3D-тоннеля.
