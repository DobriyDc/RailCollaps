В трёх парных листах левая половина показывает обрыв, правая — восстановление. Названия левого и правого путей относятся к положению на экране, а не к сторонам машиниста. Камера смотрит на нос поезда; новые участки расположены ниже него в кадре. Красный X отмечает обрыв, зелёные указатели — открытый маршрут, голубой рычаг — цель взаимодействия.

## Использование

Это визуальные концепты для обсуждения окружения, состояния пути и переключения маршрутов. Они не являются точными схемами рельсов или готовыми игровыми фонами. Геометрию стыков, длину предупредительного участка, масштаб и анимацию восстановления нужно настроить при реализации в движке. Механика восстановления показана как визуальный вариант по запросу пользователя; код игры этим пакетом не изменён.

Первоначальные варианты `concept_01_tunnel_progression_v1.png` (узкая вертикальная композиция) и `concept_02_left_gap_restored_v1.png` (другое направление соединительной ветки) сохранены как черновые. Для дальнейшей работы использовать выбранные версии из таблицы.
