# Три ключевых кадра — v1

31.10.2026. Рекомендация: **02 «Литейная аркада»**. Растровые черновики создал встроенный
`image_gen`; имя его модели инструмент не раскрывает. Codex задал арт-дирекцию, проверил
результаты и подготовил воспроизводимое приведение к палитре. Это не заявление о ручной
отрисовке растра моделью Codex.

| Кадр | Отличие |
|---|---|
| [01 «Рёбра топки»](01_furnace_390x844.png) | Круглый кирпичный свод, тёплая латунь, портрет в центральном круглом приборе; самый крупный поезд. |
| [02 «Литейная аркада»](02_foundry_390x844.png) | Стальные контрфорсы, холодный корпус, асимметричная компактная панель; больше пространства пути. |
| [03 «Глубокий свод»](03_vault_390x844.png) | Стрельчатые арки, медный корпус, два симметричных манометра и центральный портрет. |

Один момент: вход локомотива в левый поворот, видны нос, правый бок, колёса и тяга;
позади рушатся арки, полки балласта и рельсы. На приборной доске дистанция 5985, рекорд 0,
патроны 8, щит 0, спасение 0; подписи заменены значками. Слов в PNG нет.

Итоговые файлы — RGB PNG 390×844, логическая сетка 166×360, увеличение nearest.
Палитра читается непосредственно из `docs/STYLE.md`: 32 разрешённых цвета, вне палитры
**0 цветов / 0 пикселей** во всех трёх PNG. Варианты используют 28, 27 и 28 цветов.
Нецелое увеличение до размера телефона даёт логическим пикселям ширину/высоту 2 или 3 px.

`drafts/*.webp` — три исходных изображения 853×1844, сохранённые без потерь. Они не ограничены
палитрой и не предназначены для просмотра как итог. Дополнительных вариантов не генерировалось:
всего три вызова image_gen. Полные запросы — `keyframes_prompts_v1.json`, размеры, pivot,
назначение и контрольные суммы — `keyframes_manifest_v1.json`.

Воспроизведение из корня репозитория:

```powershell
python art_src/keyframes_v1/prepare.py
python art_src/keyframes_v1/prepare.py --check-only
```

Скрипт сводит мелкие штрихи черновика в логические пиксели площадным усреднением BOX,
применяет слабый упорядоченный порог Bayer 4×4, выбирает ближайший разрешённый RGB и
увеличивает nearest. Сглаживания финальных границ и полупрозрачности нет. Проверяется
также точный обратный проход через логическую сетку.

Это кадры для выбора художественного направления, не игровые фоны и не текстуры с
запечённой перспективой для движка. Объём, свет и параллакс в игре нужно собирать отдельно.
В 01 и 03 поезд опущен ниже референса ×2; 02 ближе к его игровому кадрированию.
После выбора владельца — производство по карточке 22. Проверки и ограничения: [REPORT.md](REPORT.md).
