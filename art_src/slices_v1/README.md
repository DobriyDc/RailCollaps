# Hell Tunnel — нарезка v1

38 игровых PNG: 6 состояний паровоза, 16 эффектов, 16 элементов интерфейса.
Исходные листы `hell_tunnel_01_train_v1.png`, `hell_tunnel_04_fx_v1.png` и
`hell_tunnel_05_ui_v1.png` не изменены. Генератор: `python tools/art/slice_hell_tunnel.py`
(Python 3.12 + Pillow), запуск из любой папки.

Файлы находятся в `assets/sprites/{train,fx,ui}/`. Единственный полный реестр —
`assets/sprites/manifest.json`: источник и его SHA-256, прямоугольник `[x,y,width,height]`
в исходнике, размер PNG, pivot в пикселях от левого верхнего угла, смещение содержимого,
группа, порядок в листе и номер кадра. `slices_manifest_v1.json` — указатель на этот реестр.

Нарезка использует 4-связные области альфы после обнуления значений ниже 24.
Самые крупные области задают объекты; отделённые частицы присоединяются к ближайшему
силуэту в своей строке. Межстрочные границы определяются промежутками между реальными
силуэтами, а не равномерной сеткой. Маски владения исключают попадание соседей даже
при пересечении прямоугольников. Все пиксели с альфой 24 и выше сохраняются ровно один раз.
По содержимому оставлено минимум 4 прозрачных пикселя с каждой стороны.

Факелы, дым и лава имеют по четыре кадра на общем холсте и с одним pivot на группу.
Факелы выровнены по нижней точке металлического крепления; дым и лава — по центру
основания. У паровоза pivot задан вручную по середине нижнего отвала, включая наклонённые
позы; нижние колёса в этих позах не используются как точка опоры. У UI pivot по центру.
Масштаб не меняется, для интеграции рекомендована фильтрация nearest.

`contact_sheet.png` проверен глазами: все 38 объектов целиком, без соседних элементов;
номера и имена нанесены только на контактный лист. Первоначальное присоединение отдельных
искр нижнего ряда к лаве исправлено учётом межстрочного промежутка. Исходники содержат
варианты состояний: FPS, плавность циклов и бесшовность лавы остаются задачей интеграции.
Новые изображения через генеративную модель не создавались; происхождение исходников
и промпты сохранены в `../hell_tunnel_prompts_v1.json`, операция описана в
`slices_prompts_v1.json`.

Проверка: `node tools/check.mjs --tests` — код 0, 89 тестов (финальная стена в отчёте сдачи).
