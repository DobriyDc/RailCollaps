# Обвал с магмой — v1

Оригинальный растр Rail Link: Collapse для карточки 12, 30.10.2026.
Создан встроенным **image_gen**, затем нарезан и подготовлен Pillow без зависимостей.
Полные запросы: [collapse_front_prompts_v1.json](collapse_front_prompts_v1.json).
Размеры, порядок кадров, pivots и назначения: [collapse_front_manifest_v1.json](collapse_front_manifest_v1.json).

Фронт: pivot **(128,256)** — центр нижней границы кадра, normalized **(0.5,1)**.
Остальные pivots — центр. Снаружи арки альфа 0, внутри — 255; тёмная глубина
внутри арки непрозрачна. Блоки, лавопады и поверхность магмы меняются,
силуэт и кладка удерживаются. При использовании атласа выставить UV по 256 px;
для исключения соседнего кадра при масштабировании предпочтительны отдельные PNG.

Везде nearest; спрайты без mipmaps. Материал фронта — unlit/emissive с alpha-test,
чтобы освещение сцены не погасило лаву. Декали трещин не содержат кирпичного фона.
Для магмы — repeat по X и Y, четыре фазы идут 00→01→02→03→00.
Период исходного узора 127 px, последняя строка/колонка дублируют первую:
противоположные кромки всех кадров совпадают точно.

Превью расстояний — вставка в исходный кадр-эталон с восстановлением поезда
поверх фронта по маске. Это художественный композит; подключение в сцену — отдельная карточка.
Никаких надписей в PNG нет. Узор магмы повторяется, разрывов по границе тайлов нет.

`source_*_v1.png` — нетронутые исходники генерации. `magma_quilt_base_v1.png` —
сшитая без размытия основа. Скрипт `python art_src/collapse_front_v1/build_pack.py`
воспроизводит все игровые PNG, превью, manifest и [численные проверки](validation_v1.json).
Референс разрушения прочитан по кадрам 2–6, кадр 1 не использовался;
пиксели референсов не переносились в игровые файлы.
