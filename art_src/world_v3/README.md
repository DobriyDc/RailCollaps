# Мир «Рёбра топки» — v3

Эталон: `art_src/keyframes_v1/01_furnace_390x844.png`. Черновики — встроенный image_gen
(инструмент не раскрывает имя модели); подготовка — Python 3.12 / Pillow, без новых зависимостей.
Полные запросы: `world_prompts_v3.json`; оригиналы генерации: `drafts/`.

Игровые файлы перечислены в `world_manifest_v3.json`. Палитра берётся из `docs/STYLE.md`,
проверка каждого PNG с SHA-256 — `validation.json`. Непрозрачные материалы используют
3–4 цвета на вещество; комбинированный путь включает дерево, металл и балласт.

Тайлы 128×128: стена, свод (длинная ось кирпича V), ребро арки, балласт, путь и четыре кадра
магмы. Для стены, свода, балласта и магмы повтор X/Y; для ребра и пути только Y.
Два рельса идут по V, центры U=32/96, шаг четырёх шпал 32 px. Сохраняется договор текущего
`tunnel_textures_v1`: один тайл — одна полоса, размеры 128×128. Pivot материалов [0.5,0.5].
Перспективу и освещение задаёт геометрия/свет сцены. Цветовые различия в PNG — материал,
магма — сам источник. Nearest, без bloom и сглаживания, один пиксель арта на логический
пиксель при крупнейшем ожидаемом размере на экране.

Кирпичные лица пересобраны в регулярную перевязку, у пути выпрямлены две рельсы.
Восьмипиксельный край сведён с противоположным и затем приведён к точной палитре.
Превью `previews/*_3x3.png`: регулярные швы раствора и кромки ребра/полосы намеренные,
поперечный повтор у последних не предусмотрен. Магма: тороидальный сдвиг на 32 px V,
180 мс на кадр, цикл 720 мс; все четыре перехода, включая 3→0, точные.

Воспроизведение из корня: `python art_src/world_v3/prepare.py`.
Повторная проверка: `python art_src/world_v3/prepare.py --check-only`.
Код игры и прежние ассеты не изменены; подключение к сцене выполняется отдельно.

## Четыре слоя задника

`assets/sprites/world/bg_01_void.png` … `bg_04_rubble.png`: четыре RGBA 384×256,
общий pivot [0.5,1], привязка к центру пола фронта обвала, альфа строго 0/255.
Порядок от дальнего к ближнему: пустота/магма, арка, колонна/падающая кладка,
край балласта с рельсами. Рекомендованные относительные глубины 48/36/24/12
заданы в манифесте; их единицу адаптирует интегратор к масштабу сцены.
Это отдельные фронтальные плоскости, а не нарисованная перспектива тоннеля.
Логическая ширина 384 px покрывает больше экрана и оставляет запас бокового движения.
Растр не растягивать на экран: соблюдать единую плотность пикселя при размещении плоскостей.

`previews/reference_and_layers.png`: слева утверждённый ключевой кадр, справа слои,
сложенные на тёмном фоне (×2 nearest); ниже четыре слоя отдельно и шесть материалов.
`previews/background_composite.png` — та же композиция в исходной сетке 384×256.
Превью — художественная проверка, не кадр живой игры. Освещение и проверка движущейся
камеры остаются частью интеграции; альфа-тест и depth test нужны без мягкого смешивания.
