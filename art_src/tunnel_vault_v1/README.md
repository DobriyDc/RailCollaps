## UV для карточки 13

**Это новые файлы для подключения; код сцены и старые PNG не менялись.**

- U проходит всю дугу **один раз**: левая пята `0`, замок `0.5`, правая пята `1`.
  Обе половины меша должны иметь общую координату на вершине. Старое `uScale=6`
  для ребра применять нельзя: оно размножит замок и нарушит клинчатую кладку.
- V свода направлена вдоль тоннеля; repeat V, период 128 px / четыре ряда.
  Текстура бесшовна также по U, хотя на полной дуге U следует clamp.
- V ребра проходит глубину экструзии от передней к задней кромке, clamp U/V.
  Это поверхность ребра вдоль профиля, не готовый перспективный рисунок арки.
- Манифест содержит 33 нормализованные точки эллиптического профиля
  `x=-cos(theta), y=0.75*sin(theta)`, путь экструзии и U по накопленной длине.
  Умножить профиль на радиус, прибавить высоту пяты, глубину пути — на глубину ребра.
  Для существующего 16-сегментного профиля можно брать каждую вторую точку.
- Для квадратной плотности пикселя один продольный период свода должен иметь
  физическую длину `полная_длина_дуги × 128/512`. V масштабировать по длине тоннеля;
  U считать по длинам отрезков профиля, а не присваивать равные интервалы разным граням.
  Соотношение физической глубины ребра к длине дуги — `64/1024` для той же плотности;
  если геометрия требует другого отношения, согласовать плотность при подключении.
- Nearest. Декали clamp, straight alpha blend; не запекать в повторяющуюся кладку.
  Для трещины допустима emissive-маска по оранжевым пикселям. Копоть — обычный
  тёмный alpha blend. Подвес привязать к потолку по верхнему pivot.
