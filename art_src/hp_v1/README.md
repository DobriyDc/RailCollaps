# Здоровье — hp_v1

Оригинальный арт для Rail Link: Collapse. Только новые файлы, без изменений кода игры.
Встроенный image_gen: одна генерация на группу; черновики в `drafts/`.
`prepare.py` — сборка Pillow, nearest, палитра `docs/STYLE.md`, альфа строго 0/255.

## Индикаторы

`python art_src/hp_v1/prepare.py icons` — два PNG 24×24 в `assets/ui/hud_v3/`.
Погасший индикатор использует тот же альфа-контур; фары полного выделены двумя светлыми ядрами.
Манифест: `icons_manifest_v1.json`.

## Раненый машинист

`python art_src/hp_v1/prepare.py portraits` — 12 PNG 48×48, два уровня ран для шести выражений.
`drafts/wounds.png` — единственная генерация-референс, `wounds_w1.png` и `wounds_w2.png` — общие
слои, вручную перенесённые на сетку оригинального лица. Припухлость глаза сдвигается на 1 px
для hit/fire/fall; рот, усы, оставшийся глаз и поворот головы взяты из соответствующего оригинала.
Фуражка w2 повёрнута отдельно на 8°, лицо не вращается. Манифест: `portraits_manifest_v1.json`.
`portraits_preview.png`: столбцы calm, tense, joy, hit, fire, fall; строки оригинал, w1, w2, масштаб ×4.
