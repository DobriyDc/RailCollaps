## Подключение

Это исходные листы для нарезки, ещё не подключённые игровые атласы. Раскладка приблизительная: у архитектуры и интерфейса размеры объектов различаются, поэтому равномерная автоматическая сетка может пересечь объект. Области каждого спрайта следует выделять по его фактическому силуэту, сохранять альфа-канал и добавлять прозрачные поля.

После нарезки задать pivots, масштаб и фильтрацию nearest. Паровозу нужна точка привязки на оси пути у основания; у кадров одного эффекта должны совпадать размер холста и точка привязки. Листы показывают состояния и варианты, но не гарантируют готовые плавные циклы. Для факела, дыма и лавы FPS назначается после просмотра анимации. Бесшовность лавы, геометрическую стыковку рельсов и 9-slice панелей проверить при интеграции. Текст интерфейса рисовать отдельно.

PNG — плоские растровые исходники, не многослойные Aseprite/PSD. Размеры в промптах — запрос генератору; фактические размеры брать из манифеста. Небольшой полупрозрачный шум на краях возможен; маску для нарезки проверять визуально. Существующие игровые атласы `assets/collapse_p0/` этим пакетом не заменены.
