# Демоны выпрыгивают из стен, с дистанцией — по двое (указание владельца 2026-10-30)

Сейчас демон один, редкий, прыгает спереди. Нужно: демон выпрыгивает из левой или правой стены
тоннеля к поезду; чем дальше заехал поезд, тем чаще бывает двое сразу (слева и справа). Каждого
нужно сбить своим выстрелом (тап по демону, патрон); не сбитый — удар (щит прощает один).

Правила решают сторону, число и время каждого демона (по зерну, детерминированно); сцена рисует
прыжок из стены на своей стороне и цель тапа на каждом демоне. Окно на выстрел честное: сумма окон
двух демонов успевается двумя тапами (число в отчёте).

Запрещено: в `CollapseScene.js` трогать что-либо кроме постройки и показа демона (камеру, сигналы,
палитру, обвал позади делает другая пачка); вводить демонов в первые 600 м.

## Критерии приёмки
- Тесты: сторона и число демонов по зерну детерминированы; двойные появляются не раньше
  оговорённой дистанции и чаще с её ростом; два несбитых демона без щита — падение.
- Наблюдаемо: кадр, где демон вылетает из стены сбоку; кадр с двумя демонами.
