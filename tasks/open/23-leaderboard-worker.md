# Общая таблица лидеров на Cloudflare Worker (владелец, 2026-10-31)

Своего сервера нет: GitHub Pages только раздаёт файлы, CloudStorage свой у каждого игрока, а токен
бота нельзя класть в код игры. Одна функция Cloudflare Worker с базой D1 держит токен секретом и
хранит таблицу. Старт после посадки карточки 21 (обе правят `Game.js` и `UILayout.js`).

Аккаунт Cloudflare заведён, токен @railcollapsebot заменён (владелец, 2026-10-31). Токен в чат, в
репозиторий и агентам не передаётся: владелец вводит его сам при деплое. Воркер пишет и проверяет
код локально и не деплоит: загрузка `wrangler` и деплой — отдельным шагом с разрешения владельца.

Нужно:
- `POST /score`: проверка `initData` по HMAC с токеном и свежести `auth_date` (скилл
  `telegram-miniapp`, раздел про проверку на сервере); `initDataUnsafe` не доверять;
- реплей: клиент шлёт зерно забега, журнал действий с номерами шагов симуляции (выстрелы, демоны,
  продолжение) и метры; функция переигрывает забег теми же `CollapseRules` и записывает её метры, а
  не присланные;
- версия правил `COLLAPSE_RULES_VERSION`: запись другой версии отклоняется, каждая версия — свой
  сезон таблицы, смена правил не ломает старые записи;
- `GET /top`: топ-100 и место игрока; в базе только id Telegram, имя для показа, метры, сезон, дата;
- защита: CORS только `https://dobriydc.github.io`, предел запросов на игрока;
- клиент: журнал забега без влияния на правила, отправка в конце забега, без сети игра работает
  как раньше; экран таблицы — записями `UILayout.js`;
- сборка функции одним файлом из `js/Constants.js` и `js/CollapseRules.js` скриптом в `tools/`;
  в игру и архив `server/` не едет; зависимостей в игре по-прежнему ноль.

## Критерии приёмки
- Проба: 20 зёрен — реплей журнала бота даёт те же метры, что живой забег, до метра.
- Проба: подделанные метры, чужой `initData`, просроченный `auth_date`, другая версия правил —
  отказ, записи нет.
- После деплоя владельцем: два аккаунта Telegram видят друг друга в таблице.
