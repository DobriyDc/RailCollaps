# Ядро правил забега по GDD v3

Черновик есть на ветке `wip/prototype-draft` (8/8 тестов зелёные). Принять его как сырьё, сверить с
`docs/GDD.md` §3–§7 и довести; не переписывать с нуля без причины, названной в отчёте.

Что должно быть правдой: трасса по зерну детерминирована; у каждой опасности (провал, поток лавы)
есть развилка-выход на безопасную полосу и развилка назад; провалы конечны; пять ресурсов
(ускоритель, замедлитель, щит, патроны, спасение) работают по таблице GDD §5; перевод стрелки и
выстрел по демону стоят патрон; обвал позади догоняет медленный поезд; одно продолжение за забег.

## DoD
- `js/CollapseRules.js` без зависимостей от 3D и DOM, числа — в `Constants.js` (`COLLAPSE_*`).
- Каждое правило из абзаца выше покрыто тестом, и тест краснеет, если правило снять.

## Критерии приёмки
- Бот «уходит от опасностей» проезжает 250 сегментов на трёх зёрнах без падения (тест).
- Поезд без действий падает не позже 300 с игрового времени (тест).
- Наблюдаемо в игре (после 02–03): тап по зелёной табличке уводит поезд на её полосу на стрелке.

## Критерии тестирования
- `node tools/check.mjs --tests` — код 0, стена в отчёте.
- В отчёте: какой тест покраснел при снятом правиле (хотя бы два правила).
