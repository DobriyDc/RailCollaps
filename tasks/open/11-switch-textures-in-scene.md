# Стрелочные переводы на путях вместо диагональной перемычки

Растр готов (карточка 07, `assets/textures/switches/`, манифест `art_src/switches_v1/switches_manifest_v1.json`):
3 основания (вправо, влево, в обе стороны) и 7 наложений остряков (прямо / налево / направо),
холст 384×640 в масштабе `track.png` (128 px = полоса), стыки с `track.png` 0 px.

Нужно: на каждой развилке рисовать перевод вместо повёрнутой полосы пути; остряки показывают
положение стрелки — прямо, пока стрелка не взведена, и в сторону выбранной полосы после выстрела
машиниста (`CollapseRun.armed`); поезд при переходе едет по нарисованному ответвлению.

Запрещено: менять правила (`SWITCH_LEN` и геометрия перехода — только если кривая поезда не совпадает
с ответвлением, и тогда числом в отчёте); перерисовывать растр.

## Критерии приёмки
- Кадры: перевод с остряками «прямо», тот же перевод после выстрела; поезд на ответвлении.
- Наблюдаемо: поезд идёт по ответвлению, а не поперёк шпал.

## Критерии тестирования
- `node tools/check.mjs --tests` — код 0; `await Debug3D.lint()` — 0 находок.
