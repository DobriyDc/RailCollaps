# CrazyGames: вызов другу

После обычного забега с ненулевой дистанцией кнопка «Вызвать друга» создаёт ссылку
CrazyGames через SDK `game.inviteLink`. На устройствах с системной отправкой открывается
окно отправки; иначе ссылка копируется. Если Clipboard API запрещён внутри iframe,
используется резервное копирование. Отмена не считается успешной отправкой.

Ссылка содержит зерно маршрута, дистанцию и версию правил. При открытии игра читает
`game.inviteParams`; кнопка «Принять вызов» запускает тот же маршрут со станциями и целью
побить результат. «Заново» сохраняет маршрут и цель. Некорректные ссылки и ссылки другой
версии правил открывают обычное меню. Это соревнование с результатом, без синхронного
мультиплеера и без регистрации комнаты на портале.

SDK загружается параллельно игре. Поздняя инициализация всё равно обрабатывает приглашение.
Приглашение, пришедшее через `addJoinRoomListener` во время забега, ждёт возвращения в меню:
оно не прерывает игру и не заменяет цель текущего вызова.

## Проверка и выпуск

- `node tools/check.mjs --tests`: 291 тест, код 0 (изолированная ветка).
- Новые проверки ловят потерю приглашения, подмену маршрута при повторе, ошибки копирования
  и отмену отправки. Без новой реализации Challenge три проверки падают.
- Настоящий SDK в `useLocalSdk=true`: проверены создание ссылки и чтение параметров запуска,
  принятие вызова и экран результата на 390×844 и 1280×720, без ошибок страницы.
- В Basic Launch реклама остаётся отключённой платформой. Встроенный рейтинг не включён:
  `LEADERBOARD_CRAZYGAMES = 0`, требуется приглашение CrazyGames и серверный ключ.
- Сборка: `node tools/build.mjs --version=0.1.1-cg-social`. Загружать ZIP как обновление
  игры в Developer Portal. После загрузки проверить ссылку между двумя браузерами в
  Preview: локальный режим SDK подставляет тестовое имя игры, а портал — настоящее.
- Публикация на CrazyGames в рамках этой задачи не выполнялась.

Документация платформы: https://docs.crazygames.com/sdk/game/#invite-link
и https://docs.crazygames.com/sdk/leaderboards/.
