# Ролики для Shorts, Reels и TikTok

Вертикальные ролики снимаются из самой игры, без рисования: `tools/make-clip.mjs` открывает игру в Edge без окна, останавливает цикл кадров и ведёт его сам, 30 кадров в секунду, 1080×1920. Сцену ставит `tools/clip-page.js` на настоящем забеге. Звуки, которые игра сыграла бы, записываются со временем и сводятся с музыкой, колёсами и паром через ffmpeg.

```
node tools/make-clip.mjs docs/video/scenes/01_demon.json --lang=ru,en --out=D:/Railgramm/_handoff/video
```

Нужен ffmpeg в PATH (`winget install Gyan.FFmpeg`). По умолчанию ролики пишутся в `build/clips/` (не в репозитории). Один ролик снимается около минуты.

Правила формата из `docs/marketing-plan.md`: с первой секунды опасность, без логотипа и заставки; подписи крупно, потому что смотрят без звука; в конце карточка с @railcollapsebot.

## Сцены

| Файл | О чём |
|---|---|
| `01_demon.json` | Демон вылезает из стены, виснет на кабине, бьёт, выстрел — пепел; второго снимают на стене |
| `02_collapse.json` | Обвал за спиной подходит на метр, ускоритель уводит поезд вперёд |
| `03_last_life.json` | Одна жизнь, впереди провал, выстрел по рычагу в последний момент |
| `04_station.json` | Станция в соборе: пассажиры выходят и садятся, жетоны на ремонт, отъезд |
| `05_record.json` | Две тысячи метров, ноль патронов, рычаг не сдвинуть, падение и «Побьёшь?» |

## Файл сцены

- `seed` — зерно забега; `look: "A" | "B"` — вместо зерна взять первое, у которого первая станция в этом стиле.
- `pos` — сегмент, с которого начинается сцена (10 м на сегмент); `station: N` — вместо этого начать за N сегментов до первой станции.
- `ammo`, `hp` — патроны и жизни в начале.
- `seconds` — длина; `endAt` — секунда, с которой проступает финальная карточка; `music` — громкость музыки; `rumble: { from, to, volume }` — гул обвала.
- `actions` — что происходит, по секундам `at`:
  - `demon` (`side` 1 справа, −1 слева; `wait` — сколько горит значок; `perch` — сколько дольше сидит на стене);
  - `shoot` (`side`) — тап по демону, с кольцом на месте тапа;
  - `hazard` (`kind` gap или lava, `ahead` сегментов перед носом, `len`; `fork: false` — без стрелки);
  - `fork` — выстрел по рычагу в безопасную полосу; без патронов — сухой щелчок;
  - `pickup` (`kind`: boost, ammo, shield, rescue, slow; `ahead`);
  - `collapse` — начать обвал; `front` (`till`, `from`, `gap`, `ease`) — держать обвал всё ближе к поезду;
  - `buy` (`kind`) и `leave` — на станции; `hp` (`value`).
- `captions.ru`, `captions.en` — подписи `{ from, to, text }`, `<br>` — перенос, `<b>` — золотом, `{m}` — метры забега.
- `endLines.ru`, `endLines.en` — строки финальной карточки между названием и @railcollapsebot.

После сцены дорога спокойная: опасности только те, что сцена кладёт сама.
