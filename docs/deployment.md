# Публикация Telegram и обычного веба

Игра открывается по адресу https://dobriydc.github.io/RailCollaps/ и через
https://t.me/railcollapsebot/play. С 5 ноября 2026 года GitHub Pages публикует корень
ветки **gh-pages** — готовую сборку. Ветка **main** содержит исходники; её push сам
по себе сайт больше не обновляет. Это позволяет публиковать адреса скриптов с версией
и не оставлять Telegram на закэшированных файлах предыдущего выпуска.

## Обновление

1. Проверить нужный коммит в чистом рабочем дереве: `node tools/check.mjs --tests`.
2. Если менялись правила забега, сначала обновить сервер таблицы лидеров. Он собирается
   из тех же исходников: `node tools/build-worker.mjs`, затем из `server/leaderboard` —
   `npx wrangler deploy --config=wrangler.local.toml --keep-vars`. Конфигурация с привязкой
   существующей базы локальная, в git не добавляется. Изменения схемы проверять отдельно.
3. Собрать клиент: `node tools/build.mjs --version=НОВАЯ_ВЕРСИЯ`. В `build/` попадут
   только нужные файлы, а в адресах скриптов и шрифта будет номер версии.
4. Перенести содержимое `build/` в рабочую папку ветки gh-pages. Сохранить `.nojekyll`
   и `.gitattributes`. Дополнительно перенести из исходников **privacy.html**, **terms.html**
   и **server/leaderboard/welcome.png**: на них ссылаются бот и условия покупок, но обычный
   ZIP сборщика их не включает.
5. Обновить `release.json`: версия, номер правил, коммит исходников, зона Monetag и версия
   сервера. Этот файл содержит только публичные сведения о выпуске.
6. Закоммитить и отправить gh-pages. Дождаться сборки Pages и проверить опубликованные
   файлы по прежнему адресу. Исходники и отчёт о выпуске отправить в main отдельно.

Рабочая папка последней публикации: `D:/Railgramm/_handoff/telegram-pages-20261105`.
В основной папке могут быть незавершённые изменения другой платформы; в выпуск идут
проверенные исходники и готовая сборка, а не случайное содержимое рабочего дерева.

## Monetag

Текущая зона — `12172659`, скрипт — `https://libtl.com/sdk.js`, функция —
`show_12172659`. `ADS_AFTER_LOSS = 1`. `ADS_ADSGRAM_BLOCK` пуст: в Telegram активен
только Monetag. Скрипт загружается при запросе рекламы. На CrazyGames используется
SDK CrazyGames, а на обычном вебе Telegram-реклама не запускается автоматически.

За продолжение награда даётся только при `reward_event_type === 'valued'`.
Пропуск, `non_valued`, пустая лента и ошибка не дают продолжения. Реклама после
проигрыша вызывается при выходе из итогов, один раз на забег, без наложения на
предложение продолжить. Тесты этой логики: `tests/ads.test.mjs` и
`tests/crazygames.test.mjs`.

Проверка загрузки настоящего SDK не равна проверке рекламной выдачи на телефоне.
Автоматическая проверка выпуска не запускает оплачиваемые показы или клики.
