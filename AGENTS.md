# Правила для GPT-воркеров (Codex) — Rail Link: Collapse

Ты воркер студии. Координатор и Producer — Claude: он ставит задачу через Orca, читает твой диф и
сам сажает ветку в ствол `main`. Ты делаешь ровно свою задачу в своём рабочем дереве.

Прочитай перед работой: `GAME.md` (что за игра), `art_src/*README*.md` (что уже нарисовано),
спеку своей роли в `gamestudio/roles/` и `gamestudio/roles/_common.md`. Для кода — ещё `CLAUDE.md`
и скилл из таблицы в нём.

## Если тебя запустил Orca

Вставленная преамбула с Task и Dispatch ID главнее этого файла: heartbeat, `ask` и `worker_done`
отправляй ровно её командами. Вопрос, без ответа на который нельзя продолжать, — через `ask`.
`worker_done` один раз, с `--outcome succeeded` или `--outcome failed`.

## Команды

- Ворота: `node tools/check.mjs --tests` (Node: `C:\Program Files\nodejs\node.exe`). В отчёте —
  код выхода и стена, например «`node tools/check.mjs --tests` — код 0, 1 с».
- Python с Pillow есть: `python` (3.12). Для нарезки и проверки картинок.
- Игра в браузере: `run.bat` (dev-сервер, порт 8080 или следующий свободный).

## Арт

- Только оригинальный. Не копировать чужие игры, их текстуры, логотипы, персонажей и композиции.
- Стиль задают `art_src/storyboard_tunnel_style_keyframe_v1.png` и листы `hell_tunnel_*`: тёмный
  кирпич, ржавый металл, лава, крупный пиксель, ступенчатый свет без размытия.
- Без текста в текстурах. Каждый новый пакет: PNG + `*_manifest_*.json` (файлы, размеры, кадры,
  pivot, назначение) + `*_prompts_*.json` + короткий README в `art_src/`.
- Готовые к игре файлы — в `assets/`, исходники генерации — в `art_src/`.
